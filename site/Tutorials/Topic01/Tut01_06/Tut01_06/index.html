    1. Database Connection¶

    2. SQL Queries¶

    Q1¶

    For how long has Global Bikes been in business?

    SELECT 
    MIN(date) AS first_sales_order,
    MAX(date) AS last_sales_order
FROM sales_orders
;

    ========================================

first_sales_order    last_sales_order   
-------------------  -------------------
2007-01-01 00:00:00  2016-12-31 00:00:00
(1 row affected)

    A date range is a perfectly valid, useful "answer" to this question. It is actually much more informative than say, "9"; 9 what?

    When we see the time range, we also realise that the whole of 2007 and 2016 are included, so 10 (years) would be the more accurate answer anyway. Not subtracting the dates, or years, avoids having to think about that possibility or making the mistake without realising it in the first place. So this result is better on both counts.

    DATEPART(YEAR, date) AS Year,

    Note that rather than filter the data to only return 2590, we have grouped by year instead, so that we can interpret 2590 by comparing it to prior years. This is more useful than only providing a one-row-one-column "answer".

    Exploring the data, we also need to come to understand that each row is NOT a different sale, but one product sold within a sale. We need to count the number of unique order numbers, not just count the rows to arrive at the correct result.

    To GROUP BY year requires you to self-learn about date manipulation. There is a utility function YEAR(), that extracts the year from any date.

    Q8¶

    What is Global Bikes' discounting policy? Per product (diff. disc. for each sales order line item), or per order (same discount applied to all sales order line items)?

    WITH 
order_discount AS (
    SELECT
        ordernumber,
        MIN(discount / revenue) AS min_discount_pct_temp,
        MAX(discount / revenue) AS max_discount_pct_temp,
        MAX(discount / revenue) - MIN(discount / revenue) AS diff_discount_pct_temp
    FROM sales_orders
    GROUP BY ordernumber
    HAVING COUNT(*) > 1
)
SELECT TOP 15
    ordernumber,
    ROUND(min_discount_pct_temp, 4)  AS min_discount_pct,
    ROUND(max_discount_pct_temp, 4)  AS max_discount_pct,
    ROUND(diff_discount_pct_temp, 4) AS diff_discount_pct
FROM order_discount
ORDER BY diff_discount_pct_temp DESC
;
